| Field            | Purpose                                              |
| ---------------- | ---------------------------------------------------- |
| `id`             | Unique archive reference (STAG-0001, RAD-0004, etc.) |
| `title`          | Human-readable title                                 |
| `type`           | STAG, Radio, Personnel, AAR, etc.                    |
| `classification` | Restricted, Confidential, Secret, Declassified       |
| `visibility`     | Controls whether the website shows it                |
| `era`            | Relaxed, Decline, Silence, BGG, Shadow Years, etc.   |
| `author`         | Document author                                      |
| `location`       | Where it originated                                  |
| `condition`      | Intact, Burnt, Water damaged, Fragment               |
| `confidence`     | Confirmed, Probable, Contradictory, Unverified       |
| `revision`       | Current archive revision                             |
| `serverItem`     | Links to an in-game item                             |
| `unlockEvent`    | Optional future event unlock                         |
| `tags`           | Search keywords                                      |
| `related`        | Cross references                                     |
| `body`           | Actual document text                                 |
